# 🃏 Memory Game

A simple memory card matching game built with **HTML, CSS, and JavaScript**.

## 🎮 How to Play

- Press **Start** to begin a new game.
- Click two cards to reveal them.
- If they match, they stay flipped.
- If they don't match, they flip back.
- Find all **8 pairs** before the **60-second timer** runs out.
- Matched cards are highlighted and cannot be selected again.

## 🧠 Game Logic

The game:
- Shuffles the cards.
- Keeps track of the selected cards and matched pairs.
- Allows only two cards to be selected at a time.
- Checks whether the two selected cards match.
- Uses a timer to end the game after 60 seconds.
- Resets the game state when **Start** is pressed again.

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 📱 Features

- Card flip animation
- Randomized cards
- Match detection
- 60-second timer
- Win and Game Over states
- Responsive design for desktop and mobile

## 🚀 Getting Started

Clone the repository and open `index.html` in your browser.

No dependencies or installation required.
